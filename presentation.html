class TmdbApiService {
  TmdbApiService({required this.apiKey, Dio? dio})
      : _dio = dio ?? Dio(
          BaseOptions(
            baseUrl: 'https://api.themoviedb.org/3',
            queryParameters: {
              'api_key': apiKey,
              'language': 'en-US'
            },
            connectTimeout: const Duration(seconds: 10),
          ),
        );

  // Fetch Popular Movies
  Future<List<Movie>> fetchPopular() async {
    final res = await _dio.get('/movie/popular');
    return _parseResults(res.data);
  }
}
Type-Safe Deserialization

Models & JSON Data Parsing

Converting loose JSON into strongly-typed, immutable Dart models with null-safety defaults:

lib/core/models/movie.dart
factory Movie.fromJson(Map<String, dynamic> json) {
  return Movie(
    id: json['id'] as int,
    title: json['title'] as String? ?? 'Untitled',
    overview: json['overview'] as String? ?? '',
    posterPath: json['poster_path'] as String?,
    voteAverage: (json['vote_average'] as num?)
        ?.toDouble() ?? 0.0,
    releaseDate: json['release_date'] as String? ?? '',
    genreIds: (json['genre_ids'] as List?)?.cast<int>() ?? [],
    runtime: json['runtime'] as int?,
    tagline: json['tagline'] as String?,
  );
}

1. Defensive Null-Safety

Every field uses null fallbacks (?? 'Untitled', ?? 0.0) so missing TMDB attributes will never crash the app.

2. Smart Computed Getters

Instead of polluting UI code, the model formats its own data:
• ratingFormatted: 8.433 ➔ "8.4"
• releaseYear: "1999-10-15" ➔ "1999"
• posterUrl: Prepends TMDB image CDN prefix automatically.

3. Round-trip Serialization

Includes toJson() and operator == for test verification and caching.

Provider & ChangeNotifier

State Management & Async Tri-State

Managing reactive UI states: isLoading, data, and errorMessage:

lib/presentation/providers/movie_provider.dart
class MovieProvider extends ChangeNotifier {
  List<Movie> _movies = [];
  bool _isLoading = false;
  String? _errorMessage;

  Future<void> loadCategoryMovies(MovieCategory cat) async {
    // Step 1: Set Loading
    _isLoading = true;
    _errorMessage = null;
    notifyListeners(); 

    try {
      // Step 2: Fetch & Parse
      _movies = await _apiService.fetchPopular();
    } catch (e) {
      // Step 3: Handle Error
      _errorMessage = 'Failed to load: $e';
    } finally {
      _isLoading = false;
      notifyListeners(); // Re-render UI
    }
  }
}

1. Loading State

Sets _isLoading = true and triggers notifyListeners() so the UI displays CircularProgressIndicator.

2. Success State

Populates _movies with parsed model objects and renders responsive movie cards.

3. Error State

Catches Dio network timeouts/no-internet errors and passes readable message to the UI retry widget.
